JavaScript aplicado a interfaces HTML

Eventos, formulários e APIs

Um projeto guiado para entender como o JavaScript captura ações, valida dados, altera a interface e conversa com uma API.

Fluxo da aula

submit → validar → feedback → fetch

Parte 1

Formulário validado

Preencha os campos e observe o comportamento do JavaScript. O envio não recarrega a página.

Informe seu nome completo.
Informe um e-mail válido.
Selecione seu curso.
Observe no código

O que acontece?

  1. O JavaScript encontra o formulário com querySelector.
  2. O evento submit é capturado.
  3. preventDefault() impede o recarregamento.
  4. Os valores são lidos com value.
  5. As classes do Bootstrap mudam o estado visual.
  6. A mensagem informa o resultado ao usuário.

Resumo

Conceitos principais

Evento

Ação que acontece na página, como clique, envio ou digitação.

API

Meio de comunicação entre a interface e outro sistema.

Endpoint

Endereço específico de um recurso da API.

JSON

Formato usado para representar e transportar dados.

GET

Método normalmente usado para consultar informações.

POST

Método normalmente usado para enviar informações.

PUT

Método usado para atualizar um recurso existente.

DELETE

Método usado para solicitar a exclusão de um recurso.
