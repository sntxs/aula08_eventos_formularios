Etapa 02

Eventos de clique

Clique no botão para executar uma função JavaScript.

Antes de começar

O que é: um evento é uma ação que acontece na página, como um clique.

O que faz: permite que o JavaScript execute uma função quando o botão for acionado.

Para que serve: criar interações, respostas e comportamentos para a interface.

O que observar: querySelector encontra os elementos, addEventListener observa o clique e textContent altera a mensagem.
