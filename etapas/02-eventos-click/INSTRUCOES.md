# Etapa 02 — Evento de clique

## Objetivo

Fazer o JavaScript reagir a um clique do usuário.

## Conceitos

- `document.querySelector()` encontra um elemento usando um seletor CSS.
- `addEventListener()` observa um evento.
- `click` acontece quando o botão é clicado.
- `textContent` altera o texto de um elemento.

## Como testar

1. Abra o `index.html`.
2. Clique no botão.
3. Observe a mensagem na tela.
4. Abra o Console e veja a mensagem registrada com `console.log()`.

## Desafio

Crie um segundo botão que altere a mensagem para “Você clicou no segundo botão”.
