# Etapa 04 — Validação com if/else

## Objetivo

Verificar se os dados necessários foram preenchidos antes de mostrar sucesso.

## Conceitos

- `.value` lê o conteúdo do campo.
- `.trim()` remove espaços no início e no final.
- `!== ""` verifica se o texto não está vazio.
- `if/else` escolhe um caminho de acordo com uma condição.
- `return` encerra a função quando há erro.

## Como testar

1. Envie o formulário vazio.
2. Envie apenas um campo.
3. Preencha todos os campos.
4. Compare as mensagens.

## Desafio

Adicione uma regra: o nome precisa ter pelo menos três caracteres.
