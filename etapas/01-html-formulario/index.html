Etapa 01

HTML do formulário

Nesta primeira etapa, construímos somente a interface.

Antes de começar

O que é: a estrutura HTML responsável por organizar um formulário.

O que faz: cria campos para a pessoa informar nome, e-mail, assunto e mensagem.

Para que serve: coletar informações de forma organizada e acessível.

O que observar: a relação entre label for e input id, os tipos de campo e o botão submit. Ainda não há JavaScript nesta etapa.
