Etapa 07

API com POST

Antes de começar

O que é: POST é um método HTTP usado para enviar dados a um endpoint.

O que faz: envia um objeto criado no JavaScript para a API.

Para que serve: cadastrar, criar ou encaminhar informações para outro sistema.

O que observar: method, headers, body e JSON.stringify() participam da montagem da requisição.

A resposta é simulada para estudo e não é persistida permanentemente.
Envie o formulário para ver o retorno.
