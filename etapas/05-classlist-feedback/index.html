Etapa 05

classList e feedback visual

Antes de começar

O que é: classList é a lista de classes CSS de um elemento HTML.

O que faz: adiciona e remove classes enquanto a página está funcionando.

Para que serve: mudar estados visuais sem reescrever o HTML.

O que observar: as classes do Bootstrap is-valid, is-invalid, alert-success e alert-danger representam o resultado para o usuário.
