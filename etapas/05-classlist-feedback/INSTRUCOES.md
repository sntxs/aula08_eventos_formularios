# Etapa 05 — classList e feedback visual

## Objetivo

Alterar classes do Bootstrap com JavaScript para informar visualmente se cada campo está correto.

## Conceitos

- `classList.add()` adiciona uma classe.
- `classList.remove()` remove uma classe.
- `is-valid` mostra o estado de sucesso do Bootstrap.
- `is-invalid` mostra o estado de erro.
- `d-none` oculta um elemento.
- `alert-success` e `alert-danger` mudam o feedback.

## Como testar

1. Envie os campos vazios.
2. Observe quais campos receberam o estado de erro.
3. Preencha os campos e envie novamente.
4. Veja a mensagem de sucesso.
5. Digite em um campo com erro e observe a classe sendo removida.

## Desafio

Acrescente um `select` de curso e só permita sucesso quando o curso também estiver selecionado.
