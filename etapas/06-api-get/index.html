Etapa 06

API com GET

Endpoint usado: https://jsonplaceholder.typicode.com/posts/1

Antes de começar

O que é: uma API é uma forma organizada de um sistema conversar com outro sistema.

O que faz: o método GET consulta um recurso em um endpoint.

Para que serve: buscar dados externos para exibir em uma interface.

O que observar: fetch inicia a requisição, response.json() converte a resposta e catch trata falhas.

Clique no botão para iniciar o GET.
